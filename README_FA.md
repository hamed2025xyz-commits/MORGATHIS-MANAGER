# MORGATHIS MANAGER — Android source starter

این بسته، سورس اولیه رابط اندرویدی Kivy و تنظیمات ساخت APK است؛ APK کامپایل‌شده نیست.

## وضعیت فعلی
- رابط فارسی و راست‌چینِ اولیه با تم تیره
- صفحه داشبورد و بخش‌های ماژولار
- بررسی نصب بودن کتابخانه SplusPy
- محل مشخص برای اتصال واقعی به حساب

## محدودیت مهم اتصال
مستندات عمومی SplusPy نمونه `Client(...).run()` را نشان می‌دهند، اما روش احراز هویت تعاملی و چرخهٔ ورودِ قابل استفاده از رابط موبایل باید با نسخهٔ دقیق کتابخانه و دستگاه آزمایش شود. این نسخه عمداً ادعا نمی‌کند که ورود/ارسال پیام واقعی کار می‌کند و رمز یا کد ورود را ذخیره نمی‌کند.

## ساخت APK
Buildozer باید روی Linux یا macOS اجرا شود، نه مستقیماً در Termux اندروید.
در یک محیط Linux:
1. نصب Python 3، Java، و وابستگی‌های Buildozer طبق مستندات رسمی
2. ورود به پوشه پروژه
3. اجرای `buildozer android debug`
4. فایل خروجی در پوشه `bin/` ساخته می‌شود.

## اجرا روی رایانه برای پیش‌نمایش
`pip install kivy`
`python main.py`

## فایل‌ها
- `main.py`: رابط کاربری
- `modules/splus_adapter.py`: نقطه اتصال آینده به SplusPy
- `buildozer.spec`: تنظیمات بسته‌بندی اندروید

## ساخت خودکار APK با GitHub Actions
1. یک مخزن جدید و خالی در GitHub بساز.
2. تمام محتویات این پوشه را در شاخه `main` مخزن قرار بده.
3. وارد زبانه **Actions** شو و workflow با نام **Build MORGATHIS Android APK** را باز کن.
4. روی **Run workflow** بزن.
5. پس از پایان موفق، در بخش **Artifacts** فایل `MORGATHIS-Android-APK` را دانلود کن و APK داخل ZIP را روی گوشی نصب کن.

یا پس از push کردن فایل‌ها، با هر push به شاخه main ساخت خودکار اجرا می‌شود.

**محدودیت این بیلد:** برای اینکه ساخت APK به یک وابستگی پایتونیِ تأییدنشده برای Android وابسته نباشد، SplusPy فعلاً داخل APK بسته‌بندی نشده است. این خروجی رابط اندرویدی اولیه است و اتصال مستقیم به حساب سروش‌پلاس، ورود و عملیات پیام‌رسانی در آن فعال نیست. برای فعال‌سازی اتصال باید روش رسمی/سازگار احراز هویت و وابستگی‌های قابل بسته‌بندی اندروید جداگانه پیاده‌سازی و آزمایش شوند.
